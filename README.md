# Incredible Stays 🏨

A complete, Hotel Booking Website built with React — find your perfect stay across India's most beautiful destinations.

## Tech Stack
- React 19 (functional components + hooks)
- React Router DOM (client-side routing)
- Bootstrap 5 (grid system)
- React Icons
- Context API (wishlist, bookings, recently viewed, dark mode)
- LocalStorage persistence
- Vite

## Getting Started

```bash
npm install
npm run dev
```

Then open the printed local URL (usually http://localhost:5173).

To build for production:

```bash
npm run build
npm run preview
```
